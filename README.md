# Compressor Blade Design

## Overview
This project focuses on the design and 3D modeling of an axial compressor blade using SolidWorks.

## Software Used
- SolidWorks
- AutoCAD

## Objectives
- Generate blade geometry from airfoil coordinates
- Create a 3D CAD model
- Prepare geometry for CFD and FEA studies

## Skills Demonstrated
- Aerospace Component Design
- CAD Modeling
- Surface Modeling
- Engineering Documentation
